# Run Log - Event Photo Capstone

## 1. Environment Setup & Verification (הקמת סביבה ובדיקה)
- **Repository Cloning:** ביצעתי שכפול (Clone) למאגר הפרויקט למחשב המקומי.
- **Node Version Check:** בדקתי את תאימות סביבת העבודה של Node.js.
  - *Command:* `node -v`
  - *Status:* תקין ומוצלח.

## 2. Dependencies Installation (התקנת חבילות)
- התקנתי את כל החבילות והתלויות הנדרשות לפרויקט באמצעות מנהל החבילות.
  - *Command:* `npm install`
  - *Status:* הסתיים בהצלחה מלאה וללא שגיאות.

## 3. Documentation Initialization (יצירת תיעוד)
- יצרתי את תיקיית התיעוד הייעודית `SD_docs/`.
- יצרתי והכנסתי תוכן לקבצי התיעוד הנדרשים:
  - `requirements-event-title.md` (מפרט דרישות וניתוח לפי עשר העדשות עבור עדכון שם האירוע).
  - `run_log.md` (יומן עבודה כרונולוגי המרכז את שלבי ההתקנה, ההרצה והפיתוח).

## 4. Version Control & Synchronization (בקרת גרסאות וסנכרון)
- הגדרתי את פרטי ההזדהות (Credentials) ב-Git המקומי ופתרתי את בעיות האימות.
- ביצעתי Commit ודחיפה (Push) של קבצי התיעוד למאגר המרוחק ב-GitHub (`yehuditweinbach/event-photo-capstone`).
- *Status:* מסונכרן ומעודכן לחלוטין מול ענף ה-main.
